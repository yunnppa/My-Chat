# Privacy and Safety

## User controls
- block user
- unblock user
- report user
- report post
- report message
- mute chat
- hide story
- privacy settings

## Blocking
A blocked user should not be able to:
- start prohibited interactions
- view restricted content
- send messages where product policy disallows it

Enforce blocking server-side.

## Data minimization
Collect only data needed for functionality.

Especially minimize:
- location history
- message metadata
- device identifiers
- analytics identifiers

## Account deletion
Provide an account deletion workflow.

Deletion should cover:
- authentication account
- user profile
- content according to retention/legal requirements
- stored media
- notification tokens

Use backend workflows for cascading cleanup.
